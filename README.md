# Gallium

One social app for everything: posts and photos, shorts, long videos, music and messaging.
No ads, no paywalls, and a feed the user fully controls.

## Free preview site

`docs/` is a browser-only copy of Gallium (data stays in each visitor's browser) that GitHub Pages serves for free at https://sinxer0.github.io/Gallium/. Turn it on under Settings → Pages → Deploy from a branch → `main` → `/docs`.

## Run it

Easiest: install [Node.js](https://nodejs.org) (22.5 or newer), then double-click **Start Gallium (Mac).command** or **Start Gallium (Windows).bat**. The first start loads the demo content and opens your browser. See `HOW TO START.txt`.

From a terminal:

```
npm install      # only if node_modules is missing
npm start        # http://localhost:3000, loads demo content on first run
npm run seed     # resets everything back to the demo content
```

Sign in as **demo / gallium123**, or create your own account. Every demo creator (maya, jaylen, nova, techtom, astro_lee, chefkai) uses the same password, so you can open a second browser window as one of them and message yourself live.

On a phone on the same Wi-Fi, open `http://<your computer's IP>:3000` and use "Add to Home Screen" to install it like an app.

## What's in v1

| Area | What it does |
| --- | --- |
| Home | One ranked feed of every format, with filter chips (Posts, Shorts, Videos, Music) |
| Shorts | Full-screen vertical swipe player that autoplays whatever is on screen |
| Watch | Long-form video grid, a player page with comments and an "Up next" list |
| Music | Track list with a player that keeps playing while you move around the app |
| Messages | Direct messages that arrive live (Server-Sent Events) with unread badges |
| Create | Upload any of the five formats; duration and a poster frame are read in the browser |
| Feed controls | Every rule the algorithm uses, editable: block or boost topics, creators or whole formats |
| Roadmap | Users suggest ideas or fixes and upvote them; the top of the list is what gets built next |

### How the feed works

Every surface (Home, Shorts, Watch, Music) goes through the same ranking in `server.js` (`rank()`):

1. **Never** rules are applied first and are absolute. A hidden post, a blocked creator, a blocked #topic or a blocked format is removed before anything is scored.
2. What's left is scored by freshness, who you follow, a small popularity bump, and your **More of this** boosts (creator, topics and format of every post you boosted, each with a strength slider from 1 to 10).
3. Every card says why it's there ("You asked for more #cooking", "You follow this creator").

That is the whole algorithm. There is no hidden engagement model.

## Layout

```
server.js          API and the feed ranking
db.js              SQLite schema
seed.js            demo data
public/            the whole front end (no build step): index.html, app.js, app.css, PWA manifest and service worker
seed-media/        demo photos, videos and music (generated by scripts/make_demo_media.py)
data/              created at runtime: the database and uploaded files (git-ignored)
```

## Not in v1 yet

- Video transcoding and multiple quality levels (uploads are served as-is, so use MP4/H.264 for widest support)
- Group chats, live streaming, playlists, notifications
- Moderation tools and reporting
- Hosting: it runs on one machine with local storage. Moving to production means Postgres plus object storage (S3 or similar) and a CDN for media.
